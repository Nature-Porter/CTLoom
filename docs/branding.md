# CTLoom 视觉标识

CTLoom 使用为本项目绘制的 **CT 编织标识**：紫色折线构成 C，青色经线构成 T，金色短横线表现工具与协作的交织。

![CTLoom CT 编织标识](../ctloom/assets/icon.svg)

| 资源 | 用途 |
| --- | --- |
| [icon.svg](../ctloom/assets/icon.svg) | 矢量源文件；浏览器页头和 favicon 使用同一份源文件。 |
| [icon.png](../ctloom/assets/icon.png) | 512 × 512 PNG，用于项目头像、分享和展示。 |
| [icon.ico](../ctloom/assets/icon.ico) | 多尺寸 Windows 图标。 |
| [hero.svg](images/hero.svg) | README 横幅。 |

主色为紫色 `#a78bfa`、青色 `#67e8f9`、金色 `#f0b45c`，底色为 `#101622`。终端使用同一构图的字符版本，以适应纯文本显示。

应用名称统一写作 **CTLoom**，Python 包名与启动命令为 `ctloom`。版本来自 `ctloom.__version__`。
